Data Engineering

Self-Hosted Data Lakehouse

KubernetesSparkTrinoIcebergDelta LakeUnity CatalogFastAPINext.js

A self-hostable data platform that brings the core Databricks experience — notebooks, a governed catalog, SQL warehouses, jobs, elastic Spark compute, and an AI/BI assistant — to any Kubernetes cluster you control. It runs entirely on-premise (or in your own cloud VPC) with no dependency on a SaaS control plane.

Approach

Where strong open source already exists, the platform integrates it rather than reinventing it: Unity Catalog OSS for governance, Delta Lake and Iceberg for table formats, Spark on the Kubeflow Spark Operator for compute, Trino for interactive SQL, Open Policy Agent for authorization, MinIO for object storage, and PostgreSQL for metadata.

What I built

  • Control Plane — a FastAPI service that manages workspaces, compute (Spark clusters and SQL warehouses), jobs, notebooks, and a catalog proxy, driving the Kubernetes API and Unity Catalog underneath.
  • Genie — an AI/BI assistant that turns natural language into SQL against the governed catalog, with a pluggable model layer (Anthropic, OpenAI, Azure OpenAI, or local Ollama/vLLM).
  • Workspace UI — a Next.js single-pane workspace with a catalog explorer, SQL editor, notebooks, compute, jobs, and a Genie chat.
